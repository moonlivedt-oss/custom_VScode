# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не открывай публичный issue** для проблем безопасности. Вместо этого:

- воспользуйся приватным каналом GitHub — вкладка **Security → Report a vulnerability**
  (GitHub Security Advisories) в этом репозитории;
- либо напиши автору через профиль [@moonlivedt-oss](https://github.com/moonlivedt-oss).

Опиши, что нашёл(ла), как воспроизвести и в чём потенциальный вред. Постараюсь ответить в
разумный срок; после исправления — упомяну тебя в благодарностях (по желанию).

## Что важно знать о модели угроз

MoonLight custom-bg — это один JS-скрипт, который через `be5invis.vscode-custom-css` исполняется
в интерфейсе VS Code. Он не открывает сеть и не собирает телеметрию сам по себе, но принимает
внешние данные (импорт конфига, код образа, свои пути картинок). Поэтому:

- **Санитизация.** Всё, что приходит извне (импортированный JSON, код «Поделиться»,
  `localStorage`), проходит через `mergeCfg` (`src/core/config.js`): принимаются только значения
  известного типа и диапазона. Цвета — строго `#rrggbb`, шрифт терминала — из белого списка;
  строки, уходящие в CSS, экранируются — вырваться из `url('...')` или `font-family` и дописать
  произвольный CSS нельзя.
- **Сетевые картинки — выключены по умолчанию** (`allowRemoteImages: false`). Импортированный или
  чужой конфиг не может заставить редактор молча сходить в сеть за картинкой (защита от утечки IP
  и трекеров). Пользователь включает это сам и осознанно.
- **UNC/SMB-пути** (`file://host/...`) для картинок блокируются — чтобы чужой конфиг не спровоцировал
  запрос по сети с передачей учётных данных.
- **Ограничение размера.** Импорт и хранилище отсекаются по размеру (>256 КБ).
- **Безопасный режим.** Если сборка CSS упала (например, из-за сломанной ручной правки), плагин
  включает минимальный безопасный CSS: кнопка `BG` и панель остаются доступны, чтобы можно было
  сбросить настройки, а не остаться со сломанным редактором.

Если ты нашёл(ла) способ обойти любую из этих защит (инъекция CSS, обход блокировки сетевых
картинок, вынуждение сетевого запроса из чужого конфига и т.п.) — это как раз то, о чём стоит
сообщить приватно.
