# История версий

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект использует одиночный номер версии (v14, v15, …), он же в `package.json`.

## Unreleased

### Аудит: исправления и новое (2026-10-08)
- **Фото-наборы под Moon Core.** Ядро по умолчанию кладёт модуль файлом `mooncore-mod-mlbg.js`
  рядом с `workbench.html` (`moonCore.moduleFiles`), и база картинок бралась из папки VS Code —
  наборы писали «фотографии не найдены», если не задана «Папка плагина». Теперь под Moon Core
  папку ресурсов всегда даёт ядро (на стенде — петлевой http).
- **Сжатая сборка в репозитории.** `custom-bg.min.js` (её грузит Moon Core) больше не в
  `.gitignore`; CI и pre-commit проверяют, что она пересобрана из `src/`.
- **Синхронизация между машинами.** Слайдшоу, время суток, библиотека и подтянутый вид больше
  не отправляются в Settings Sync (`autoChange`); своя отправка ждёт первого подтягивания при
  старте — правка первых секунд больше не затирает вид с другой машины.
- **Сгенерированные наборы.** Любой новый конфиг (импорт, образ, пресет, резерв, копия дня,
  синхронизация, отмена/повтор, другое окно) принимается через `adoptCfg`/`candidateCfg`: хвост
  наборов готовится ДО проверки индексов, поэтому выбор, яркость, акцент, имя и привязки
  ген-набора не теряются. Отмена/повтор больше не рассинхронизируют список и `genSets`.
  Удаление ген-наборов (`pruneSetRefs`) чистит и репозитории, время суток, избранное, точки фокуса.
- **Шейдеры.** Контекст WebGL освобождается сразу (`WEBGL_lose_context`); смена акцента не
  пересоздаёт холст; после потери контекста фон пробует вернуться (до 3 раз с паузой).
- **Резерв на диске** укладывается в лимит файла данных Moon Core (старые копии дня
  отбрасываются), а не перестаёт обновляться.
- **Выключение модуля** закрывает открытые окна (панель, меню, переключатель, «?», знакомство),
  дописывает резерв и снимает отложенные таймеры (`later`).
- Журнал ошибок не пустеет после 50 разных ошибок; счётчик ошибок без данных о диагностике —
  «неизвестно», а не 0 (берётся из статусбара); подсказка первого запуска ведёт в
  «Эффекты → Стили»; устаревшие упоминания Custom CSS убраны из баннеров и `package.json`;
  точка фокуса проверяет номер набора; кэш картинок проверяет карту яркости; компаньон на Linux
  различает папки по регистру.

### Добавлено (2026-10-08)
- **Утро и вечер.** «По времени суток» делит сутки на четыре части: необязательные наборы на
  первые и последние часы дня (1–6 ч, по часам или по рассвету/закату), «как днём» — по-старому.
- **Набор в файле проекта.** `moonlightBg.projectSet` в `.vscode/settings.json` (имя или номер
  набора) едет вместе с репозиторием и важнее всех авто-правил. Новое правило «Файл проекта» на
  вкладке «Авто-смена»: записать текущий набор в файл или убрать его (через компаньон).
- **«Что изменится».** Импорт файла, чужой код образа и база из settings.json сначала
  показывают список изменений с кнопкой «Примерить»; применяется только по «Применить».
- Смоук: 496 проверок (в т.ч. запуск модулем из файла рядом с оболочкой и старт с ген-набором).

### Вид от установщика (2026-10-02)
- **Присланный вид фона больше не проигрывает localStorage.** Установщик moon-bundle кладёт образ
  в файл данных модуля с меткой `install: { id, force }`. С `force` образ применяется поверх уже
  настроенного (раньше на машине, где фон хоть раз запускался, он молча игнорировался), прежний
  конфиг уходит в резерв «Восстановить». Метка одноразовая; без `force` — как раньше, только
  для пустого localStorage. Если установщик отработал при открытом VS Code, образ принимается
  перед следующей записью резерва, а не затирается им.
- Ген-наборы при старте дозагружаются из того же источника, что и конфиг (раньше — только из
  localStorage, и выбранный ген-набор из резерва на диске сбрасывался на «0»).
  Смоук: 460 проверок.

### Новое API Moon Core (2026-09-29)
- **Фон по ветке, языку и репозиторию — и без компаньона.** Живые данные (ветка, есть ли
  изменения, «владелец/репо», папка проекта, ошибки по всему проекту, язык и расширение файла)
  теперь приходят и из событий VS Code самого Moon Core (`mc.vscode.on`). Компаньон, если он
  стоит, по-прежнему важнее; без обоих — как раньше, чтение статусбара. В диагностике видно
  источник: «события VS Code (Moon Core)».
- **Выключение без перезагрузки окна.** Moon Core выключает модуль сразу — фон снимает всё своё:
  стиль, кнопку BG, панель, виджеты и холсты, циклы анимации, секундный тикер, наблюдатели,
  подписки окна, классы и CSS-переменные. Включили снова — фон встаёт как был
  (`src/core/mooncore-api.js`, `mlbgStop`).
- **Команды фона в палитре Moon Core** («Moon Core: Команды модулей»): следующий и предыдущий
  набор, панель «Фон и дизайн», быстрый переключатель, включить/выключить. Объявлены в
  манифесте модуля и в рантайме.
- **Общая шина модулей.** Акцент фона (`mlbg.accent`: hex и rgb) и текущий набор (`mlbg.set`) —
  для соседних модулей; окно «Документация C++» перекрашивается по ним. Событие окна
  `mlbg-accent` осталось для старых соседей.
- Со старым Moon Core (без нового API) всё это молча пропускается. Смоук: 454 проверки.

### Исправлено (2026-09-27)
- Пакет самодостаточен: внутри лежит сборка Moon Core (`moon-core.bin`, берётся из
  `../moon-core/dist` или `MOON_CORE_VSIX`), компаньон при первом запуске ставит её сам; кнопка
  «Поставить Moon Core» в проверке установки тоже берёт её, а не просит выбрать файл. Значки панели
  (`assets/ui`) в пакет больше не копируются — они уже вшиты в сборку.
- Картинки по адресу file:/// (выбор файла и папки в панели, библиотека, «Папка плагина») не
  грузились в настоящем VS Code: оболочка отклоняет любой запрос file://. Рантайм переводит такие
  адреса в vscode-file://vscode-app/ (appFileUrl).
- Выбор картинок больше не предлагает .avif: вне папок VS Code такие файлы окну не отдаются.

### Добавлено (Moon Core)
- **Модуль Moon Core** — плагин можно встраивать ядром Moon Core как модуль `mlbg`, без
  be5invis / custom-ui-style и без импорта в settings.json. Объявлен в `mooncore-module.json`
  (корень репозитория, для разработки: путь к папке в настройке `moonCore.modules`) и в
  `extension/package.json` (`moonCore.modules`, для установленного компаньона).
- Через Moon Core путь к картинкам берётся из помощника модуля (`base`), ручная «Папка плагина»
  не нужна. Загрузчик в «Система → Загрузчик» и в диагностике определяется точно («Moon Core»),
  кнопка «Скопировать импорт» в этом режиме скрыта.
- Среда (прозрачность окна и пр.) приходит от компаньона событием `env` по мосту ядра вместо
  файла-пролога; стиль пересобирается, когда она пришла.
- Компаньон видит Moon Core: не прописывает импорт, в проверке состояния показывает Moon Core
  и предлагает убрать старый импорт, если он остался.

- **Живые данные по мосту Moon Core** — ветка, ошибки, язык файла и папка приходят от компаньона
  событием `live` только своему окну, без опроса файла. Прежний путь (JS-файл в globalStorage,
  подключаемый через `<script src>` раз в 3 с) оболочка VS Code блокирует, и данные молча не
  доходили; заодно окна больше не делят одну ветку на всех. Фон по ветке/языку переключается
  сразу по событию, а не циклом самолечения.
- **Резерв конфига на диске** — после каждой правки (с паузой 2 с) копия конфига уходит в файл
  данных модуля Moon Core. Если `localStorage` очищен (крупное обновление VS Code), конфиг
  восстанавливается из резерва при старте. Образ `moonlightBg.config` компаньон кладёт в пустой
  резерв новой машины. «Система → Диагностика» показывает время последнего сохранения.
- **Журнал ошибок** `logErr` — ошибки самолечения, виджетов, сборки и вставки стиля больше не
  глотаются: каждая разная ошибка один раз уходит в консоль и в журнал «Moon Core» (Output),
  повторы считаются, последние видны в «Системе → Диагностике».
- **Сжатая сборка по умолчанию** — `node build.js` всегда пишет и `custom-bg.min.js`; модуль Moon Core
  и пакет компаньона встраивают её (426 КБ вместо 757 КБ кода на старте).
- **Образ фона в профилях вида Moon Core** — профиль Moon Core сохраняет и образ фона (те же
  ключи, что у кода «Поделиться»: набор, акцент, эффекты, прозрачности), а при применении — в том
  числе по контексту (язык, папка, ветка) — возвращает его. Машинно-зависимое (путь к картинкам,
  свои картинки, привязки к проектам) не трогается; текущий конфиг перед применением уходит в резерв.
- **Компаньон под Moon Core** — вместо импортов для Custom CSS / Custom UI Style: среда и живые
  данные по мосту, проверка состояния (Moon Core, разрешён ли модуль, лишние старые импорты),
  уборка старых файлов пролога и живых данных. Custom UI Style нужен только для настоящей
  прозрачности окна.

### Исправлено
- Через Moon Core скрипт исполняется в `<head>` до появления `<body>`: первое самолечение падало
  на создании холстов виджетов (нашлось благодаря журналу ошибок). Виджеты ждут `body`, самолечение
  повторяется сразу после разбора документа.
- Защита от двойного запуска: если плагин внедрён двумя путями сразу (загрузчик и Moon Core),
  работает только первый экземпляр (`window.__MLBG_RUNNING__`), второй не заводит вторую
  панель, стиль и таймеры.
- «Убрать импорт» находит и импорт, указывающий на `custom-bg.js` в другой папке (например, в
  репозитории), а не только путь внутри установленного компаньона.
- Проверка состояния снова предлагает «Поставить загрузчик», когда его нет (кнопка не
  появлялась из-за обращения к несуществующему полю).

### Добавлено (v20: движок читаемости, цвет, производительность, надёжность)
- **Адаптивный скрим** (`autoRead`, включён по умолчанию) — фон гасится не целиком ползунком,

- **Метр читаемости** («Вид → Яркость набора») — контраст кода к РЕАЛЬНОЙ подложке (смесь темы

  акцента до нужного контраста, не меняя оттенка.
- **Кэш метрик картинок** — яркость, акцент, палитра, карта 8×8 и мини-превью 96×64 сохраняются
  в localStorage. Следующий запуск сразу рисует превью нужным цветом (LQIP), а полная картинка
  тихо подменяет его, когда догрузится: ни пустого кадра, ни прыжка акцента на старте.
- **Числа — в CSS-переменных** — перетаскивание ползунка больше не пересобирает и не

  воркбенча. Главный режим отказа CSS-плагина — переименованный класс после обновления

### Добавлено (накоплено с v19)
- **Живой фон** (эффект `liveBg`) — у градиентных и процедурных наборов фон медленно
  панорамируется (увеличенный `background-size` + keyframes-пан), «дышит», а не стоит статично.
  Фото-наборы не трогает (у них Ken Burns). Гаснет при reduced-motion и в эконом-режиме FPS.
- **Анимации интерфейса** (`uiAnim`) — мягкое появление палитры команд/автодополнения/подсказок/
  поиска, плавные переходы вкладок и строк списков, выезд уведомлений. Только CSS; появления
  гаснут при reduced-motion.
- **Акрил** (`acrylic`) — усиленное «матовое стекло» на весь воркбенч (сайдбар, панель,
  актив-бар, доп-бар, статусбар, титлбар, вкладки) одним тумблером, поверх точечных «стекло …».
  Внутриредакторная эстетика Acrylic/Mica; настоящая прозрачность до рабочего стола требует
  отдельного расширения vibrancy (поясняется в подсказке). Учитывает «уменьшить прозрачность».
- **Шлейф курсора** (`cursorTrail`) — тающий след акцентного цвета за указателем мыши на
  canvas; клики проходят сквозь. Гаснет при reduced-motion и в эконом-режиме FPS.
- **Питомец-компаньон** (`pet`) — процедурный кот в правом нижнем углу над статусбаром (ноль
  ассетов): моргает и водит хвостом, оживляется при печати, настораживается при ошибках в коде.
  При reduced-motion сидит неподвижно.
- **Фон по git-ветке** (секция «По ветке») — набор закрепляется за текущей веткой (main/master —
  один, фиче-ветки — другой). Приоритетнее слайдшоу/времени суток, уступает «фону по проекту».
- **Фон по языку файла** (секция «По языку») — набор закрепляется за расширением активного файла
  (`.py`, `.md`, …); расширение читается из подписи активной вкладки. Самый низкий контекст-приоритет.
- **Рассвет/закат** — у «авто-набора по времени суток» появился выбор режима границ дня:
  «Часы» (как раньше) или «Рассвет/закат» по координатам (широта/долгота), рассчитывается
  локально без сети.
- **Библиотека картинок** (секция «Библиотека») — свой список локальных путей; при включённом
  «Крутить библиотеку» они по очереди показываются в зоне редактора и сменяются по таймеру
  слайдшоу. Компаньон может дополнить список папкой через `window.__MLBG_LIBRARY__`.
- **Витрина/скринсейвер при простое** (секция «Витрина») — после N минут без ввода поверх
  редактора плавно появляются крупные часы, дата и имя набора; любое действие возвращает
  редактор (первая клавиша гасится, чтобы не попасть в текст).
- **Статистика сессии** (`stats`) — компактная сводка в статусбаре (время, файлы, нажатия) и
  полная в «Данные → Статистика» (время в потоке, лучший стрик непрерывной печати). Только в
  памяти сессии, никуда не отправляется.
- **Дальтоник-безопасные акценты + контраст** — в секции «Картинка»: палитра акцентов Окабэ-Ито
  (различимых при основных типах дальтонизма) и строка WCAG-контраста акцента к тёмной подложке
  набора с предупреждением при контрасте < 3.

### Оффлайн-анализ ассетов (Python)
- **`scripts/analyze_sets.py`** — инструмент подготовки наборов, которому не мешают
  ограничения рантайма. `import-master.js` работает через ffmpeg и сравнивает средние по
  колонкам; здесь полноразмерный анализ на Pillow/numpy:
  - **карта «занятости»** по градиентам, а не по яркости: пёстрая тёмная листва мешает читать
    код не меньше светлого пятна, и в средних по колонкам это не видно;
  - **подбор вырезов перебором** позиций под реальную раскладку окна (шаг 2 % по ширине),
    с текущей позицией среди кандидатов и порогом «менять только при выигрыше от 5 %»;
  - **проверка читаемости всего каталога** разом — с учётом стартовой прозрачности каждого
    набора, а не абстрактной средней;
  - **разнообразие палитры**: пары наборов с акцентами ближе 20° по оттенку. Прогон по
    текущему каталогу нашёл 5 таких пар — три синих и две янтарных;
  - **контактный лист** всех мастер-кадров одной картинкой (`--sheet`).
- Python — только dev-зависимость (`requirements-dev.txt`); рантайм и основной поток сборки
  его не требуют, «ноль зависимостей» остаётся в силе.

### Данные из хоста расширений
- Компаньон-расширение перестало быть только установщиком: теперь оно отдаёт рантайму
  **настоящие данные редактора** — ветку и удалённый репозиторий из git API, счётчик ошибок
  из `languages.getDiagnostics`, `languageId` активного файла, папку воркспейса. Раньше всё
  это выскребалось из вёрстки статусбара и заголовка окна и ломалось на обновлениях редактора.
- Канал — маленький файл `mlbg-live.js`, который расширение переписывает ТОЛЬКО при
  изменении данных, а рантайм переподключает своим циклом самолечения (раз в 3 с, отдельного
  таймера нет). Замер цены цикла в живом браузере: **0.9 мс медиана, 1.9 мс p95**, теги
  `<script>` в DOM не накапливаются.
- Живые данные — предпочтение, а не требование: без компаньона (или при выключенном git)
  всё работает по-прежнему через скрейпинг DOM. Источник виден в диагностике строкой
  «Данные редактора».
- **Фон по репозиторию** (`autoRemote`) — привязка, которую из DOM сделать нельзя вовсе:
  ключ «владелец/имя» берётся из git-remote, поэтому один и тот же проект, склонированный в
  две разные папки, открывается с одним фоном. Приоритет: проект > репозиторий > ветка > язык.
- «Фон по языку» теперь опирается на настоящий `languageId`, а не на расширение из подписи
  вкладки; старые конфиги с ключами вида «js» продолжают работать — ключ ищется сначала по
  языку, потом по расширению.

### Проверка типов
- **`npm run typecheck`** (входит в `npm run check` и в CI отдельным джобом): TypeScript

  связи между ними до сих пор не проверялись ничем, кроме запуска.

  - «Избранное» после выноса в отдельный модуль звало `sectionByTitle`/`selectTab`/

    ReferenceError. Ни смоук, ни e2e этого не видели — панель собиралась, а по чипу никто не
    кликал. Починено, закрыто e2e-тестом.

    часам»; второй перевод затирал первый, и эффект «Часы» показывался в EN как «Hours».
    Режим переименован в «По часам» — заодно понятнее и по-русски.
  - Ещё два дубля-пустышки в словаре EN и переиспользованное имя переменной в смоук-тесте.
- Ключевые структуры описаны JSDoc-типами: `MlbgSet` (запись набора со всеми пятью
  источниками фона), контекст `fxBlocks`, каталог поиска панели. Мостики окна и вендорные

  (тумблеры `particles`/`pomodoro` пересобирают панель).
- Кнопка **«Акцент из картинки» скрыта на генеративном наборе** (у него нет картинки для сэмпла;
  раньше клик всегда давал ошибку-тост). Если в зону редактора подложена своя картинка — кнопка снова доступна.

### Как это устроено
- Скрытые вкладки помечены `hidden`, поэтому ловушка `Tab` и стартовый фокус их не видят.
- Смоук-тест теперь прямо строит панель (`togglePanel`) в мини-DOM-стабе — ловит битую
  проводку контролов, которую проверка одного `buildCSS` не видела.
