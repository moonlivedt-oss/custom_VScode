# История версий

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект использует одиночный номер версии (v14, v15, …), он же в `package.json`.

## v19 — 2026-09-05

Крупный релиз: локализация RU/EN, профили быстрого старта, авто-бюджет FPS, синхронизация
через `settings.json`, пятая вкладка «Данные», защита DOM-скрейпинга, интеграционный тест
(Playwright), веб/Codespaces-темы и health-check в компаньон-расширении, улучшенные подсказки.

### Добавлено
- **Диагностика установки** — секция «Система» → «Проверить установку»: отчёт о состоянии
  (версия, тема, активный набор, папка и загрузка картинок, активен ли custom-css) с копией
  в буфер для issue.
- **Сезонные частицы** — стиль «Сезон (авто)»: зима — снег, весна — сакура, лето — светлячки,
  осень — дождь (по системному месяцу).
- **История изменений (Undo/Redo)** — пошаговая отмена правок вида в пределах сессии: кнопки
  в «Система» + хоткеи `Ctrl+Alt+Z` / `Ctrl+Alt+Y`. Авто-смены слайдшоу/по времени в историю
  не попадают.
- **Поиск по панели** — поле над баром вкладок: переход к любой секции (и отдельному эффекту)
  на любой вкладке с разворотом и подсветкой.
- **Новые эффекты**: **Тон акцентом** (тонировка воркбенча, сила — ползунком), **Читаемость
  кода** (мягкая тень глифов над картинкой без сдвига курсора), **Реакция на ошибки** (мягкая
  красная подсветка статусбара, когда в коде есть ошибки — счётчик читается из DOM статусбара).
- **Процедурные наборы** (без ассетов): «Звёздное поле», «Дюны», «Грейн» — текстура рисуется
  на canvas в data-URL; при недоступном canvas зона откатывается на градиент.
- **Установщик** `install.js` (+ `install.ps1` / `install.sh`, `npm run setup`) — прописывает
  путь к `custom-bg.js` в `vscode_custom_css.imports` найденных редакторов; JSONC-настройки не
  трогает (показывает сниппет), делает бэкап перед записью.
- **Поддержка форков** — «фон по проекту» читает заголовок Cursor / VSCodium / Windsurf /
  Code - OSS, а не только «Visual Studio Code».
- **Заготовка расширения** (`extension/`) — тонкая обёртка, прописывающая импорт автоматически
  (зависит от `be5invis.vscode-custom-css`). Не опубликована — упаковка за автором.
- **Локализация интерфейса (i18n)** — панель, тосты, диагностика, статусбар переведены на
  английский; язык выбирается автоматически по языку VS Code или вручную («Система → Язык
  панели»: Авто / Русский / English). Русский остаётся исходным языком и ключом словаря —
  отсутствие перевода не может сломать русский UI. Новый модуль `src/core/i18n.js`.
- **Профили быстрого старта** — «Система → Профили»: пять готовых образов вида (Спокойный,
  Фокус, Презентация, Минимал, Максимум) настраивают фон и эффекты одним кликом; выбранный
  набор/картинки/язык сохраняются. При первом запуске — мягкая одноразовая подсказка.
- **Авто-бюджет производительности** — на слабой машине при устойчиво низком FPS тяжёлые
  эффекты (Aurora, пульс, часть частиц) автоматически приглушаются (класс `body.mlbg-perfsave`),
  а при восстановлении кадров возвращаются. Тумблер «Авто-бюджет FPS» в «Эффекты».
- **Синхронизация через `settings.json`** — «Система → Синхронизация»: скопировать строку для
  `settings.json` (объект `moonlightBg.config` едет с Settings Sync) и подтянуть базовый образ
  на эту машину. Компаньон-расширение прокидывает конфиг как `window.__MLBG_SEED__`; на новой
  машине с пустым `localStorage` он становится отправным (см. `loadCfg`/`seedConfig`).
- **Health-check в компаньон-расширении** — команда «MoonLight BG: проверить состояние
  установки» (`moonlightBg.health`): отчёт (стоит ли `be5invis`, прописан ли импорт, на месте
  ли `custom-bg.js`, обновлялся ли VS Code) с кнопками-действиями. После апдейта VS Code —
  авто-подсказка перевключить Custom CSS (один раз на версию) + указатель на fix-checksums.
- **Веб / Codespaces** — расширение получило веб-точку входа (`extension-web.js`, поле
  `browser`), поэтому **темы MoonLight работают в vscode.dev / Codespaces**. Кастомный фон в
  вебе по-прежнему невозможен (ограничение custom-css) — расширение это поясняет. Жёсткая
  `extensionDependencies` на `be5invis` снята (иначе веб-установка блокировалась) — зависимость
  теперь мягкая, `be5invis` предлагается поставить через health-check.
- **Защита DOM-скрейпинга от дрейфа вёрстки** — чтение git-ветки, счётчика ошибок и имени
  проекта сведено в `src/core/scrape.js` с учётом «здоровья» селекторов; если под новой версией
  VS Code селектор перестал находиться, это видно в «Диагностике» (вместо тихой поломки).
- **Минифицированная сборка** — `npm run build:min` -> `custom-bg.min.js` (безопасный стриппер
  комментариев/отступов, ноль зависимостей, −44% размера). В репозиторий не коммитится.
- **Интеграционный тест (Playwright)** — `test/e2e.spec.js` + `test/fixture.html`: реальный
  Chromium открывает скелет воркбенча с собранным `custom-bg.js` и проверяет живой DOM (кнопка
  BG, инжект `<style>`, открытие панели, авто-локализация). `npm run test:e2e`, отдельный
  CI-джоб; Playwright — dev-зависимость, основной smoke остаётся ноль-зависимостей.

### Изменено
- Смоук-тест: **мини-линтер инвариантов** (FX_LIST ↔ DEFAULTS.fx, PARAMS ↔ DEFAULTS.fxp,
  корректность диапазонов, белый список стилей частиц, EN-словарь без «дыр», fx-ключи PROFILES
  ⊂ DEFAULTS.fx, INFO ↔ INFO_EN) + проверки i18n/профилей/seed/скрейпинга/perf. Всего **247** проверок.
- **Локализация подсказок** — тексты `INFO` улучшены и переведены (параллельный `INFO_EN`);
  перевод — в одной точке (`infoDot`/`infoText`). Попап «?» переоформлен: матовое стекло,
  стрелка-указатель, плавное появление, подстройка под тему.
- **Чистка** — удалён мёртвый код (`hasSeedConfig`, `scrapeAnyBroken`); свод версии к **v19**
  (`APP_VERSION`, `package.json`, бейджи и таблица наборов в README — теперь 25 наборов).
- Версия релиза вынесена в единую константу `APP_VERSION` (баннер в консоли и диагностика).
- Сборка склеивает **13** модулей (добавлены `src/core/scrape.js` и `src/core/i18n.js`).

## v18 — 2026-09-03

### Добавлено
- **Aurora** — «полярное сияние» за кодом: медленный размытый градиент из палитры набора
  (акцент + два спутника), под текстом. Скорость — ползунком «Aurora сек». Opt-in.
- **Спотлайт** — затемнение экрана по краям со светлым «окном» вокруг курсора; радиус —
  ползунком «Спот радиус». Opt-in, следует за мышью.
- **Пульс печати** — активная вкладка мягко пульсирует акцентом, пока идёт набор. Opt-in.
- **Новые стили частиц**: светлячки (пульсируют яркостью), дождь (струи), конфетти
  (цветные вращающиеся прямоугольники из палитры).
- Перф частиц: переиспользование объектов вместо аллокаций, без `save/restore` для круглых
  стилей; троттлинг чтения git-ветки.

### Исправлено
- Версия сведена к единому `v18` (баннер в консоли, `package.json`, бейдж и упоминания в README).
- **Спотлайт**: z-index поднят так, чтобы затемнение накрывало весь воркбенч (а не только
  редактор) и оставалось под панелью настроек — как и задумано.
- **Код образа** («Поделиться») больше не сбрасывает согласие «Разрешить сетевые картинки»:
  применение чужого кода не отключает твои собственные удалённые картинки.
- Слияние `ui.collapsed`: длинный ключ пропускается по отдельности, а не обрывает разбор
  остальных секций.
- Самолечение стиля: наблюдатель следит за `<head>` — если VS Code выкинет наш `<style>`,
  он вернётся сразу, а не в течение трёх секунд.
- Smoke-тест теперь проверяет, что в `src/` нет многострочных шаблонных литералов (иначе
  их сломал бы сдвиг отступа при сборке).

## v16 — 2026-08-31

### Добавлено
- **8 новых эффектов** (все в панели «Эффекты», у каждого — подсказка «?»):
  - **Тускнеть неактивные** — неактивные группы редактора притухают, взгляд держится на активной
    (частый запрос к VS Code: dim inactive editor).
  - **Режим чтения** (`Ctrl+Alt+R`) — фон редактора почти гаснет ради максимальной читаемости кода;
    сайдбар и панель остаются оформленными.
  - **Стекло палитры** — матовое стекло для палитры команд, автодополнения и всплывающих подсказок.
  - **Акцент поиска** — виджет поиска/замены и подсветка совпадений красятся акцентом набора.
  - **Миникарта сквозь** — миникарта становится полупрозрачной, фон просвечивает (ярче по ховеру).
  - **Акцент отступов** — активная направляющая отступа и парная скобка в цвете набора.
  - **Совпадения слова** — все вхождения выделенного слова подсвечиваются акцентом.
  - **Стекло sticky** — матовое стекло закреплённой прокрутки (sticky scroll).
- **Стили частиц**: точки / звёзды / снег / сакура / пузыри (снег и сакура падают сверху вниз).
  Выбор — в секции «Эффекты»; стиль входит в код «Поделиться».
- **Поиск по эффектам** — поле-фильтр над списком (эффектов уже за 30).

### Изменено
- **Панель разложена по вкладкам-категориям** — вместо одной длинной прокручиваемой колонки
  из дюжины секций теперь **4 вкладки**: **Набор** (набор, слайдшоу, по времени, по проекту),
  **Вид** (яркость, картинка, эффекты), **Терминал**, **Система** (папка плагина, пресеты,
  поделиться, экспорт/импорт, сброс). Видна только одна вкладка за раз — панель стала заметно
  короче. Секции внутри вкладки по-прежнему сворачиваются.
- Бар вкладок «прилипает» к верху при прокрутке длинной вкладки (например «Вид»).
- **Активная вкладка запоминается между запусками** (`cfg.ui.tab`), а авто-пересборка панели
  (слайдшоу/смена набора) не сбрасывает на первую вкладку. Мастер-тумблер закреплён над вкладками.
- Тонкие акцентные эффекты (стекло палитры/sticky, акцент поиска/отступов, совпадения слова)
  включены по умолчанию — они лишь докрашивают уже видимые элементы под палитру набора.
  Заметно меняющие поведение (тускнеть неактивные, миникарта сквозь, режим чтения) — по умолчанию выкл.

### Исправлено (логика панели)
- «Сила эффектов» и «Стиль частиц» больше не отдельно от тумблеров — **числовая сила и стиль
  частиц теперь внутри секции «Эффекты»**, рядом с самими переключателями.
- Параметры **зависимых эффектов скрыты, когда эффект выключен**: «Частиц, шт» и «Стиль частиц»
  — только при включённых «Частицах», «Помидор, мин» — только при включённом «Помидоре»
  (тумблеры `particles`/`pomodoro` пересобирают панель).
- Кнопка **«Акцент из картинки» скрыта на генеративном наборе** (у него нет картинки для сэмпла;
  раньше клик всегда давал ошибку-тост). Если в зону редактора подложена своя картинка — кнопка снова доступна.

### Как это устроено
- Скрытые вкладки помечены `hidden`, поэтому ловушка `Tab` и стартовый фокус их не видят.
- Смоук-тест теперь прямо строит панель (`togglePanel`) в мини-DOM-стабе — ловит битую
  проводку контролов, которую проверка одного `buildCSS` не видела.

## v15 — 2026-08-30

### Добавлено
- Два новых генеративных набора: **16 · Сакура** (`#f5c2e7`) и **17 · Янтарь** (`#fab387`).
  Всего наборов теперь 18 (12 фото + 6 генеративных).
- Плавный **предпоказ набора при наведении** на чип: фон мягко «примеряется» без клика.

### Изменено
- У генеративных наборов теперь **своя форма градиента по зонам**: редактор — диагональ,
  сайдбар — обратная диагональ, панель — радиальный градиент (зоны больше не одинаковые).
- Предпоказ вынесен в отдельный `previewMode` (не трогает сохранённый `cfg.mode`) и получил
  дебаунс наведения, чтобы не дёргаться при проезде курсора по ряду чипов.

### Исправлено
- Предпоказ больше не «залипает», если закрыть панель по `Esc` во время наведения на чип
  (удалённый из DOM чип не всегда шлёт `mouseleave`).
- Предпоказ теперь работает и в режиме «случайно», и при включённом «фоне по проекту»
  (раньше `activeIndex` игнорировал `cfg.mode` и превью не было видно).
