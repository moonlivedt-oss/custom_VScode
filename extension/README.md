# MoonLight custom-bg

**Живой фон и панель оформления для VS Code — прямо внутри редактора.**

Картинки по зонам · наборы со своей палитрой · фоны без единого ассета · слайд-шоу<br>
Движок читаемости кода · шейдеры на GPU · настоящая прозрачность окна · 37 цветовых тем · RU / EN

## Что это

Обычная тема меняет только цвета. Плагины «картинка на фон» ставят один статичный кадр за
редактором — и на этом всё.

MoonLight custom-bg — это один самодостаточный скрипт, который добавляет **полноценную панель
оформления внутрь редактора**: 37 наборов фонов, полсотни эффектов, движок читаемости кода
поверх картинки, фон под проект / репозиторий / ветку / язык файла, и всё это настраивается
мышкой, без правки файлов.

Расширение ставит и настраивает всё за вас: сам плагин и картинки уже внутри пакета.

## Установка

1. Поставьте это расширение.
2. При первом запуске оно предложит поставить **загрузчик** — расширение, которое внедряет
   скрипт в окно редактора. Достаточно нажать кнопку:
   - **Custom UI Style** (рекомендуется) — переживает обновления VS Code и открывает настоящую
     прозрачность окна (Mica / vibrancy);
   - **Custom CSS and JS** — классический вариант.
3. Подтвердите перезапуск редактора.

Готово: справа в статусбаре появится кнопка **`BG 0`**, по клику открывается панель
**«Фон и дизайн»**. Быстрый переключатель наборов и эффектов — `Ctrl+Alt+P`.

## Возможности

- **37 наборов** — 12 фото-наборов, 8 мастер-кадров (один кадр 21:9 на весь набор, зоны — его
  вырезы), 6 градиентных, 7 процедурных и 4 шейдерных (кадр считает видеокарта). У каждого свой
  акцентный цвет, который перекрашивает интерфейс целиком.
- **Движок читаемости** — фон гасится точечно там, где кадр светлее комфортного порога, а метр
  контраста показывает числом, читается ли код, и умеет подобрать прозрачность сам.
- **Палитра из картинки** в OKLab — акцент и его спутники берутся из фона так же, как это
  делают pywal и Material You.
- **Настоящая прозрачность окна** (Mica на Windows 11, vibrancy на macOS) — одной командой,
  когда установлен Custom UI Style.
- **Фон под контекст** — под проект, удалённый репозиторий, git-ветку, язык открытого файла,
  время суток (в том числе по реальному рассвету и закату) или по таймеру слайд-шоу.
- **~50 эффектов** — матовое стекло, Ken Burns, виньетка, полярное сияние, спотлайт, шлейф
  курсора, питомец-компаньон, частицы, помидор, часы. Каждый с пояснением и живым превью.
- **37 цветовых тем** — палитра каждого набора выгружена в настоящую тему VS Code: работает
  даже там, где фон недоступен (веб, Codespaces).
- **Бережно к машине** — авто-бюджет FPS, экономия от батареи, уважение к системным
  «уменьшить движение» и «уменьшить прозрачность».

## Что делает расширение

- кладёт внутрь себя собранный `custom-bg.js` и картинки — ставить и прописывать пути вручную не нужно;
- прописывает импорт в настройки того загрузчика, который у вас установлен;
- отдаёт плагину **точные данные редактора** — git-ветку и репозиторий, счётчик ошибок, язык
  активного файла, папку проекта (без него это добывается разбором вёрстки и ломается на
  обновлениях);
- следит за здоровьем установки: после обновления VS Code инъекция слетает, и расширение
  подсказывает это одним сообщением;
- включает настоящую прозрачность окна отдельной командой.

## Приватность

Плагин не ходит в сеть. Сетевые картинки выключены по умолчанию, и импортированный чужой конфиг
не может их включить. Настройки хранятся локально; перенос между машинами — по вашему явному
действию через `settings.json`.
